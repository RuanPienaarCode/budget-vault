Data flow at a glance

How to read this map

Every figure the plugin shows is derived from a markdown file the user could have written by hand. This document walks each page in nav order and, for every number, chart or badge on it, names the function chain that produced it and the file it came from. Line numbers are as of the working tree on 8 September 2026; another session edits this repo concurrently, so search by function name if a number has drifted.

Which pages move with the period pill

Period-scoped: Dashboard (hero, trend, donut, budget table), Transactions, Budget, Debt (payments card only), Accounts (flow column, sparkline, drawer period fields only).

Anchored on today, ignore the pill: Dashboard health / money-left / position cards, Score, Savings, Assets, Owed, Services, Notes, Plan, Tax, Loans, Report (it hides the pill and has its own), Import.

Where money gets filtered

Only period.js:summaryInRange (:668) applies the four vetoes: row excluded, non-budget account, foreign-currency account, and outflows from an earmarked account (reported as "funded from savings"). Transfers are skipped entirely (:731). net is accumulated before any classification (:753), so a classification bug mislabels money rather than losing it. The Transactions table applies none of these; everything measuring an account rather than the budget (reconcile, periodActivity, splitFlows, chargeIndex, buildIndex) deliberately keeps excluded rows.

Two storage rules

  • table-schema.js is the one column declaration per flat table (ADR-0003): rowToObject for reads, headerLines / rowLine / mdTableFile for writes, usedColumns drops an unused trailing optional column so a single-currency vault never grows a Currency column. Order is frozen history, guarded by tests.
  • io.js has two roots. Budget-relative (readFile, writeFile, patchFile, fileAt, mdFilesIn …) prefixes the budget folder and refuses escaping it. Vault-root (writeVaultFile, fileAtVaultPath, readVaultFile, ensureVaultFolder …) is for destinations the user names: Reports/ and Exports/. Mixing them is the 1.28.0 dead-button bug. patchFile is the only body-preserving write; trashFile the only deletion (vault .trash).

Period model and the shell

Two period shapes (period.js:1-20, ADR-0001). YYYY-MM is a payday month running from month_start_day of the previous calendar month; the name is stable however the boundary is tuned. YYYY-MM-DD is an interval period named for its first day, derived from period_anchor + period_days; the anchor matters only modulo the interval. Whole-day arithmetic is in UTC day numbers so DST cannot add or lose a day.
